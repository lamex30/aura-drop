# Иконки предметов и кейсов

Все PNG-иконки в этой папке — эмодзи-иллюстрации из проекта **Twemoji**
(Twitter Emoji), версия 14.0.2, формат 72×72, прозрачный фон.

- Источник: https://github.com/twitter/twemoji
- Лицензия: [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Копирайт: Copyright 2020 Twitter, Inc and other contributors

Лицензия CC-BY 4.0 разрешает свободное использование (включая коммерческое)
при условии указания авторства — этот файл и служит таким указанием.

Имя каждого файла — hex-код Unicode-кодпоинта соответствующего эмодзи
(например, `1f988.png` = 🦈 U+1F988 SHARK). Список сопоставлений
"эмодзи -> файл" смотри в полях `emoji`/`sprite` в `js/config/items.js`
и `js/config/cases.js`.
