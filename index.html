Эта игра продаётся

«Аура Дроп» — готовая казуальная игра для детей, сделанная для Яндекс Игр: симулятор открытия кейсов с персонажами, колесом апгрейда, инвентарём и таблицей лидеров.

Здесь вы играете в демо без рекламы. Продаётся полностью готовая версия с рекламными элементами, которую можно сразу загружать на Яндекс Игры.

Что входит в полную версию

  • Подключённый Yandex Games SDK (инициализация, LoadingAPI.ready)
  • Rewarded-реклама: «+50 монет», «Бесплатный кейс», «Бонус» к шансу апгрейда
  • Полноэкранная реклама каждые 4 открытия кейса — с обязательным отсчётом «Реклама через 3…» по правилам Яндекса
  • Облачные сохранения прогресса через Player Data API (+ запасной localStorage)
  • Таблица лидеров Яндекс Игр
  • 29 кейсов, 55 персонажей с артами, настроенная экономика и редкости
  • Чистый исходный код на HTML / CSS / JS без сборщиков — легко менять под себя

В демо кнопки, которые в полной версии работают за просмотр рекламы, срабатывают бесплатно — чтобы можно было оценить все механики.
